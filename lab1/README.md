# Time Manager Lab

Лабораторная работа по FastAPI на тему **программа-тайм-менеджер**.

В репозитории три папки:

- `practice_1_1` — базовое FastAPI-приложение с временной базой в памяти.
- `practice_1_2` — FastAPI + PostgreSQL + SQLModel.
- `practice_1_3` — финальный проект: PostgreSQL, SQLModel, Alembic, CRUD, JWT-авторизация, нормальная структура проекта.

Основная версия для сдачи находится в `practice_1_3`.
