# Отчёт по лабораторным работам

Данный сайт содержит отчёты по трём лабораторным работам по веб-разработке.

## Состав работ

| № | Название | Основные технологии | Статус |
|---|---|---|---|
| 1 | Реализация серверного приложения FastAPI | FastAPI, PostgreSQL, SQLModel, Alembic, JWT | Выполнено |
| 2 | Потоки, процессы, асинхронность | threading, multiprocessing, asyncio, aiohttp | Выполнено |
| 3 | Docker, источники данных и очереди | Docker Compose, Redis, Celery, FastAPI | Выполнено |

## Общая тема проекта

В качестве предметной области выбрана **программа-тайм-менеджер**. Система позволяет хранить пользователей, задачи, категории, теги и записи времени. В последующих лабораторных работах к этой базе был подключён парсер веб-страниц, сохраняющий заголовки страниц в существующую таблицу тегов.
