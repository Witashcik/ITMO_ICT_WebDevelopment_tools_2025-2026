# Проверка и защита

## Что показать по ЛР1

1. Открыть Swagger UI: `http://127.0.0.1:8000/docs`.
2. Показать регистрацию пользователя через `POST /auth/register`.
3. Показать вход через `POST /auth/login`.
4. Показать JWT-авторизацию через кнопку `Authorize`.
5. Создать категорию, тег и задачу.
6. Прикрепить тег к задаче.
7. Добавить запись времени.
8. Выполнить `GET /tasks/{task_id}` и показать вложенные объекты.


## Что показать по ЛР2

1. Запустить `python .	ask1_sum
un_all_sum.py`.
2. Показать, что все три подхода вернули корректную сумму.
3. Запустить `python .	ask2_parser
un_all_parser.py`.
4. Показать, что сайты обработались, заголовки получены и сохранены в БД.


## Что показать по ЛР3

1. Запустить `docker compose up --build`.
2. Открыть `http://127.0.0.1:8000/docs`.
3. Открыть `http://127.0.0.1:8001/docs`.
4. В основном API выполнить `POST /parser/parse`.
5. Выполнить `POST /parser/parse-async`.
6. Скопировать `task_id` и проверить его через `GET /parser/tasks/{task_id}`.
7. Показать в Docker Desktop сервисы: `app`, `parser_service`, `db`, `redis`, `celery_worker`.
