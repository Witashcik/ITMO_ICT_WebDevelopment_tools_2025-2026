# Отчёт по лабораторной работе 3

## Цель работы

Цель лабораторной работы — упаковать FastAPI-приложение, базу данных и парсер в Docker, а также реализовать вызов парсера через HTTP и через очередь задач.

## Архитектура

В проекте реализованы следующие сервисы:

| Сервис | Описание |
|---|---|
| `app` | основное FastAPI-приложение из ЛР1 |
| `parser_service` | отдельное FastAPI-приложение для парсинга веб-страниц |
| `db` | общая база данных PostgreSQL |
| `redis` | брокер очереди задач |
| `celery_worker` | обработчик фоновых задач |

Все сервисы используют одну общую PostgreSQL-базу. Отдельные базы под микросервисы не разворачиваются.

## Подзадача 1. Упаковка приложения, базы и парсера в Docker

Для основного приложения создан `Dockerfile.app`.
Для сервиса парсера создан `Dockerfile.parser`.
Для Celery worker создан `Dockerfile.worker`.

Все сервисы запускаются через `docker-compose.yml` командой:

```bash
docker compose up --build
```

## Подзадача 2. Вызов парсера из FastAPI

В основном FastAPI-приложении добавлен роутер `app/routers/parser.py`.

Эндпоинт:

```text
POST /parser/parse
```

Он принимает URL, отправляет HTTP-запрос в сервис `parser_service`, получает результат парсинга и возвращает его клиенту.

## Подзадача 3. Вызов парсера через очередь

Для фоновой обработки добавлены Redis и Celery.

Эндпоинт:

```text
POST /parser/parse-async
```

Он ставит задачу парсинга в очередь Redis. После этого `celery_worker` забирает задачу, парсит страницу и сохраняет результат в PostgreSQL.

Для проверки статуса задачи используется эндпоинт:

```text
GET /parser/tasks/{task_id}
```

## Хранение данных

Парсер извлекает заголовок HTML-страницы и сохраняет его в таблицу `tag`, созданную в первой лабораторной работе.

Для записей парсера используется технический пользователь `parser_bot`.

## Вывод

В ходе работы FastAPI-приложение, база данных, сервис парсера, Redis и Celery worker были упакованы в Docker и объединены в единую систему через Docker Compose. Парсер можно вызвать как напрямую по HTTP, так и асинхронно через очередь задач.
