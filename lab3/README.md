# Лабораторная работа 3

Тема: упаковка FastAPI-приложения в Docker, работа с источниками данных и очередью задач.

В проекте объединены результаты предыдущих лабораторных:

- FastAPI-приложение тайм-менеджера из ЛР1;
- PostgreSQL-база из ЛР1;
- парсер веб-страниц из ЛР2;
- прямой HTTP-вызов парсера из основного FastAPI;
- асинхронный вызов парсера через Redis + Celery.

## Состав сервисов

В `docker-compose.yml` описаны сервисы:

| Сервис | Назначение |
|---|---|
| `app` | основное FastAPI-приложение тайм-менеджера |
| `parser_service` | отдельный FastAPI-сервис парсера |
| `db` | одна общая PostgreSQL-база данных |
| `redis` | брокер сообщений для Celery |
| `celery_worker` | воркер, который выполняет задачи парсинга в фоне |

Важно: используется одна общая база PostgreSQL. Отдельная база под каждый сервис не создаётся.
